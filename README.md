# Wurst Client 🧇

Wurst Client 7.51.2, ported to **NeoForge** for **Minecraft 1.21.1**. ✨

## Build & install 🛠️

You'll need Java 21 and NeoForge 21.1.185.

```powershell
.\gradlew.bat build
```

Put `build/libs/Wurst-Client-NeoForge-7.51.2-MC1.21.1.jar` in your Minecraft profile's `mods` folder, then launch with NeoForge. 🚀
